## 📖 Format Ebook

Ebook panduan ini tersedia dalam beberapa format:

- **HTML:** `public/docs/buku-panduan-spo-sd-peradaban.html` - Buka di browser, bisa dicetak ke PDF
- **Markdown:** `public/docs/buku-panduan-spo-sd-peradaban.md` - Bisa diedit dan dikonversi ke format lain

### Cara Menggunakan Versi HTML

1. Buka file `public/docs/buku-panduan-spo-sd-peradaban.html` di browser
2. Untuk mencetak ke PDF:
   - Tekan `Ctrl + P` (Windows) atau `Cmd + P` (Mac)
   - Pilih "Save as PDF" sebagai printer
   - Klik "Save"

### Cara Menggunakan Versi Markdown

1. Buka file dengan text editor atau Markdown viewer
2. Untuk konversi ke PDF, gunakan tools seperti:
   - Pandoc: `panduan.md -o panduan.pdf`
   - Typora
   - VS Code dengan extension Markdown PDF

## 🎯 Target Pengguna

Ebook ini ditujukan untuk:

- **Admin Sekolah:** Pengelola sistem, siswa, tagihan, dan laporan
- **Bendahara:** Staf keuangan yang memverifikasi dan memproses pembayaran
- **Orang Tua:** Wali siswa yang membayar tagihan sekolah

## 📝 Catatan Penting

- Semua transaksi dicatat dalam audit trail untuk keamanan
- Verifikasi bukti pembayaran memakan waktu maksimal 1x24 jam
- Simpan kuitansi pembayaran untuk arsip pribadi
- Hubungi admin jika mengalami kendala

## 🔐 Keamanan

- Gunakan password yang kuat dan jangan dibagikan
- Logout setelah selesai menggunakan aplikasi
- Jangan mengakses aplikasi di perangkat publik
- Laporkan aktivitas mencurigakan ke admin
